# sasrec_metamorphic_project
序列推荐系统通过建模用户按时间顺序产生的历史交互行为预测下一步可能感兴趣的物品，已广泛应用于课程推荐、电子商务、新闻推荐和视频推荐等场景。现有研究大多以Recall、NDCG和HitRate等准确率指标为核心，较少从软件分析与测试角度评估模型在噪声行为、行为缺失、相似物品替换和顺序扰动下的稳定性。由于推荐系统输出不存在唯一正确答案，传统测试预言难以直接适用。为此，本文将蜕变测试引入序列推荐模型鲁棒性分析，将模型抽象为以用户行为序列为输入、以Top-K推荐列表为输出的被测软件系统，设计噪声插入、序列截断、相似物品替换和顺序扰动四类蜕变关系，并提出基于Jaccard@K、Rank Difference@K和Violation Rate的自动化测试流程。
